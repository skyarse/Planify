# План задач

Нативный планировщик для Linux и KDE Plasma с локальным хранением задач. Интерфейс ориентирован на Planify 4.20.0. Ядро приложения написано на C++, интерфейс использует Qt 6 Widgets, база — SQLite.

## Сборка для разработки

Для сборки через CMake нужны компилятор с поддержкой C++20, Qt 6 Widgets, Network, SQL с драйвером QSQLITE, pkg-config и libical. На Fedora эти зависимости предоставляют пакеты `gcc-c++`, `cmake`, `qt6-qtbase-devel`, `qt6-qtbase`, `libical-devel` и `pkgconf-pkg-config`.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
./build/plan-tasks
```

Для сборки Flatpak используется `local.plan.tasks.yml` и KDE SDK 6.11. Режим `--demo` загружает вымышленные задачи во временную базу для проверки интерфейса.

## Что уже работает

- Локальные проекты, секции, список и доска, задачи и подзадачи.
- Поиск, метки, приоритеты, даты, закрепление и простые повторения локальных задач.
- Импорт списков и задач из Baïkal в локальную копию для просмотра. В диалоге импорта указывается конечный HTTPS-адрес `dav.php`. Пароль действует до закрытия приложения. Успешный импорт обновляет локальную копию. При сбое предыдущая копия остаётся на месте. Импорт использует только методы чтения CalDAV.
- Открытие локальной базы и редактирование локальных задач без сети.

В ветке разработки появились окно «Параметры», импорт календарей из файлов .ics, резервные копии SQLite и обучающий проект. Импорт резервной копии добавляет отсутствующие проекты и задачи, сохраняя существующие записи.

В ветке разработки карточка задачи раскрывается в списке. В ней доступны даты, метки, приоритет, ссылки, напоминание, последнее завершение и меню действий. Напоминания показываются в открытом приложении.

В диалоге новой задачи можно выбрать «Входящие», локальный проект или список Baïkal. После сохранения приложение показывает созданную задачу. Desktop-версия создаёт задачи и сохраняет изменения обычных задач Baïkal, включая завершение и повторное открытие. Изменения защищает проверка ETag, а после записи приложение получает подтверждённое состояние с сервера. Для Baïkal доступны вложения-ссылки. Повторяющиеся задачи, перенос и удаление в Baïkal пока выполняются в исходном клиенте.

## Android

Мобильная сборка для Android 14 и новее. На телефоне доступны локальные задачи и подзадачи, проекты, даты, приоритеты, повторы, метки, поиск и оформление. Импорт из Baïkal создаёт локальную копию задач для просмотра. Изменения в локальных задачах хранятся на телефоне.

Сборка для разработчиков использует JDK, Android SDK Platform 36, Build Tools 36.0.0 и `zip`. Скрипт `android/build.sh` создаёт тестовый APK, а `android/test.sh` проверяет обработку ответов CalDAV. Для обновления установленной тестовой сборки нужен APK с тем же ключом подписи.
