# Функции Planify для переноса в «План задач»

Ориентир — выпущенная версия Planify 4.20.0. Список охватывает пользовательские функции настольного приложения, Quick Add, Quick Find, CLI и системные интеграции.

## Задачи, даты и напоминания

| Функции Planify | Состояние в «Плане задач» |
| --- | --- |
| Создание, правка, завершение, возврат в активные и удаление | Локально работают. В Baïkal доступны создание, правка обычных задач, завершение и возврат в активные. Удаление на сервере предстоит перенести. |
| Компактная форма, выбор списка и раздела, добавление подзадачи, создание из текущего проекта или даты в календаре | Компактная форма и выбор назначения работают. Подзадачи создаются локально. Перенести все точки входа, шаблоны создания и действия на заголовках календаря. |
| Вложенность подзадач, раскрытие, переупорядочивание, перенос между родителями, отображение завершённых подзадач | Основная локальная вложенность и чтение связей Baïkal есть. Нужны перетаскивание, перенос и настройки раскрытия. |
| Название, описание, форматирование Markdown, ссылки, предпросмотр, проверка орфографии | Название и обычный текст есть. Markdown для описания проекта частично добавлен. Нужны редактор Markdown задач, предпросмотр и проверка орфографии. |
| Дата и время, отдельный крайний срок, быстрые даты, календарь, распознавание дат из текста, перенос просроченных задач | Есть дата и отдельный срок. Нужны время, расширенные быстрые даты, распознавание и перенос с сохранением правил повтора. |
| Повторы по расписанию и от даты завершения, исключения, следующее повторение, управление отдельным экземпляром | Есть простые локальные правила и чтение повторов Baïkal. Перенести расширенные правила и безопасные записи повторов на сервер. |
| Напоминания на дату и время, несколько напоминаний, автоматически относительно срока, уведомления, звук завершения | Есть одно абсолютное напоминание и уведомление при запущенном приложении. Нужны несколько VALARM, относительные напоминания и полноценная фоновая доставка. |
| Приоритеты, метки, закрепление, шаблоны, ссылки и файлы, журнал изменений и последнее завершение | Базовые поля есть. Нужны полноценная библиотека шаблонов, журнал, управление вложенными файлами и сохранение всех форматов на поддерживаемых серверах. |
| Контекстные действия над задачей — копирование, дублирование, экспорт iCalendar, перенос и удаление | Основные локальные действия доступны. Нужны безопасные перенос и удаление в Baïkal, а также переносы поддеревьев и разделов. |
| Массовый выбор, копирование, перемещение, изменение даты, приоритета и меток, завершение и удаление | Выбор нескольких задач и копирование добавлены. Предстоит перенести остальные массовые операции и их применение к серверу с обработкой частичных ошибок. |

## Проекты и представления

| Функции Planify | Состояние в «Плане задач» |
| --- | --- |
| Проекты, родительские проекты и группа учётной записи, избранное, название, описание, emoji или цвет, крайний срок и переопределение Markdown | Основные проекты есть. Добавлены параметры проекта и избранное. В Baïkal новые параметры действуют локально. Иерархия проектов и серверное редактирование календаря ещё нужны. |
| Контекстное меню проекта и меню в заголовке, дублирование, обновление источника, общий доступ, почта, PDF, архив, восстановление и удаление | Добавлены оба меню, обновление Baïkal, копирование текста проекта, подготовка письма, базовый PDF, локальный архив и восстановление. Дублирование Baïkal создаёт локальную копию, удаление доступно локальным проектам. Нужны серверное управление, полноценный общий доступ и расширенный PDF с описаниями, секциями и цветными метками. |
| Разделы — создание, редактирование, ручной порядок, сворачивание, архивирование и перенос | Локальные создание, переименование и порядок есть. Нужны новые операции и представление разделов CalDAV. |
| Список и доска, перенос карточек и разделов перетаскиванием, ручной порядок, раскрытие всех задач, вставка из буфера | Список, доска и вставка текста в форму есть. Нужны раскрытие всех задач, перетаскивание и серверный порядок. |
| Сортировка и направление, фильтры по срокам, приоритетам, меткам, включение и поиск завершённых, виды по проектам | В проектах есть настройки списка и доски, основных сортировок, направления, одного приоритета, одной метки, срока и завершённых. Нужны наборы фильтров, отдельный поиск завершённых и такой же контроль в остальных представлениях. |
| Входящие, Сегодня, Предстоящие, Завтра, Все задачи, срочность, без даты, повторяющиеся, без меток, закреплённые и завершённые | Есть Входящие, Сегодня, Предстоящие, метки, закреплённые и завершённые. Остальные встроенные представления и детальные фильтры предстоит перенести. |
| Метки — свои цвета, управление метками и источниками, отображение только активных, выбор сразу нескольких меток | Есть метки задач и фильтры по меткам. Нужны полноценное управление, цвета и составные фильтры. |

## Синхронизация, календарь и интеграции

| Функции Planify | Состояние в «Плане задач» |
| --- | --- |
| Локальный режим, несколько учётных записей, свой список Входящих у источника, ручная и автоматическая синхронизация, индикаторы и ошибки | Есть локальная работа и один набор настроек подключения Baïkal. Новая сборка запоминает пароль через системное хранилище. Нужны несколько независимых подключений, настройки источников и управляемая синхронизация. |
| Надёжные офлайн-изменения и очередь синхронизации после перезапуска, повтор неуспешных операций, согласование конфликтов | Текущая сборка подтверждает изменения обычных задач сервером и защищает их ETag. Нужна очередь офлайн-записи с разрешением конфликтов и проверкой восстановления после сбоя. |
| CalDAV, Nextcloud/ownCloud, авторизация через GNOME Online Accounts, Nextcloud Deck и Todoist | CalDAV проверяется на тестовом сервере, Baïkal — основной целевой сценарий. Нужны все остальные адаптеры, несколько учётных записей, OAuth и платформенное обнаружение. Поддержка общей спецификации не подтверждает все сценарии конкретного провайдера. |
| События календарей и их видимость по источникам, представления дня, диапазона, месяца и просроченных задач | Есть импорт локальных событий iCalendar и их отображение в «Сегодня». Нужны внешние календари, управление источниками и расширенные виды. |
| Преобразование запланированных задач проекта в события отдельного подключённого календаря | Предстоит перенести. Это отличается от обмена задачами через Baïkal. |
| Quick Add вне главного окна, сочетания клавиш, команды в заголовке, сохранение назначения и серийное добавление | Компактная форма и клавиатурное добавление внутри приложения есть. Нужны системный запуск, команды, шаблоны полей и добавление подряд. |
| Quick Find по задачам, описаниям, проектам, разделам и меткам, подсветка совпадений, быстрые команды, системный поиск GNOME | Есть поиск по названию, заметкам и меткам задач. Нужны остальные типы результатов, быстрые команды и системная интеграция KDE. |
| CLI — добавление, список и обновление задач, список проектов, резервное копирование, JSON и D-Bus API | Предстоит перенести CLI и интерфейс автоматизации. |
